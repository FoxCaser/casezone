# CaseZone V2

Повноцінний full-stack каркас CaseZone:
- Node.js + Express
- SQLite
- реєстрація/вхід
- серверний баланс
- серверне випадкове відкриття кейсів
- інвентар
- анімація відкриття

## Запуск
1. Встановити Node.js 20+
2. У папці проєкту:
   npm install
   npm start
3. Відкрити http://localhost:3000

## Важливо
`/api/test-topup` — лише тестове поповнення і не повинно залишатися доступним у публічному продакшні.

Для реальних платежів потрібно підключити платіжного провайдера, перевіряти webhook на сервері, робити idempotency, refunds, limits, KYC/AML/вікові та інші вимоги, що застосовні до моделі бізнесу.

Для реальних Steam-предметів потрібен окремий Steam trade/inventory layer і правила Steam.
